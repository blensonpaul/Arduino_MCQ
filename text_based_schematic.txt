┌──────────────────────────────────────────────────────────────────────────────┐
│                             IMPORTANT NOTES                                  │
└──────────────────────────────────────────────────────────────────────────────┘

[1] ANTENNA INSTALLATION
    • Cut a 17cm straight solid-core wire
    • Solder to the ANT pad on both TX and RX modules
    • Keep antenna vertical for best omnidirectional coverage
    • Without antenna: ~5m range | With antenna: 50-100m range

[2] POWER CONSIDERATIONS
    • Master: Must use USB to computer (for Serial Monitor)
    • Slaves: Use USB power bank or 9V battery via Vin pin
    • Total current per slave: ~80mA (RF modules + LEDs active)
    • 9V battery lasts ~8-10 hours of continuous use

[3] DEVICE ID CONFIGURATION
    • Edit this line in slave code: #define DEVICE_ID 1
    • Make each slave unique: Device 1, 2, 3, 4, ... etc.
    • Maximum supported: 50 devices (configurable in master code)

[4] TESTING PROCEDURE
    ① Upload master code to one Arduino
    ② Upload slave code to multiple Arduinos (change DEVICE_ID each)
    ③ Power on master, open Serial Monitor (9600 baud)
    ④ Power on slaves one by one
    ⑤ Press keypad buttons to test answer submission
    ⑥ Verify: Orange LED (waiting) → Green LED (confirmed)

[5] TROUBLESHOOTING
    • No communication: Check antenna installation
    • Multiple slaves interfere: System handles this automatically
    • LED doesn't light: Check polarity (long leg = anode = +)
    • Keypad not working: Verify 4-wire connection to D2-D5

[6] ASSEMBLY TIPS
    • Use breadboard for prototyping, then move to perfboard
    • Label each slave device clearly (ID number on case)
    • Use different colored wire for 5V (red) and GND (black)
    • Hot glue RF modules to prevent movement/disconnection
